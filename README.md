# Oleh Plysiuk · AI Video Creator

Portfolio site: **https://olegplysiuk-lab.github.io**

- `/`: Lumen, a lens jellyfish, rises through a 3D ocean past the films and into a ring of reels.
  Built with three.js r128 (in `js/three/`), no build step. Films play on the page from `media/full/`,
  work cards show light previews from `media/card/`, the reel ring plays short loops from `media/`.
- `/services/` and `/pl/uslugi/`: services, work for agencies, interactive websites, process, FAQ and contact (EN, PL).
- `/ai/`: a plain grid of the works made with generative AI.
- `/v2/`: test page with Oleh's hologram guide (not indexed).
- `robots.txt`, `sitemap.xml`, `llms.txt`: for search engines and AI answer engines. Fonts are self-hosted in `fonts/`.

The pages are built from the sources in the `first-project` repository (`tools/build-site.py`, `tools/build-v2.py`,
`tools/build-services.py`).
